A portfolio where you can see the story of two best friends. Our favourite music, films and, of course, projects and achievements. 🌠🎧🌸🗿

  How to use the project🗿💪
The project features three main buttons: "Home," "Our Portfolio," "What We Love," and "Our Projects."
You can click these buttons to learn more about us. At the bottom, you’ll also find our email addresses and Instagram links; feel free to contact us with questions about the project or just to chat.

  What the project is for🐋✨🎧🌠
This project was designed as a portfolio; I created it for myself and my friend. Visitors can also find inspiration here to create a similar portfolio with their own friends.

  Information about the development process🍛☮️🪸
I used HTML and CSS to build the project. Some parts were challenging—especially the beginning—since this is one of my first projects and I was a bit nervous. However, it all worked out well.
 Features implemented🌸🥥🤩
 
I created four buttons, each containing information about my friend and me. On the "Home" button, you can see a childhood photo of us and get a brief overview of who we are. The "Portfolio" button reveals our names and achievements. The "What We Love" button took a long time to create, as it showcases our favourite playlists, singers, actors, and movies. Finally, the last button displays projects we’ve created previously.

I hope you feel inspired to create your own project with a friend. If you’d like to collaborate with me, feel free to get in touch via the email address listed at the bottom. Thank you! 😉❤️🍘🍙🍤🍣
